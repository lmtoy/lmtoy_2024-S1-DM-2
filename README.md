# 2024-S1-DM-2

this project observes the Taurus Molecular Cloud-1 in 12CO and 13CO in bank=1, in
two different setups, while bank=0 is tuned to a "fake" restfreq of 109.992,trying
to find signal at 109.782 (C18O) and 110.201 (C13CO).

Tuned to vlsr=164 km/s

12CO:  strong
C18O:  clear
13CO:  maybe
CN:    nothing yet

## Multiple lines

In the current pipeline only a single line, picked by vlsr=, dv= and dw= can be choosen.
